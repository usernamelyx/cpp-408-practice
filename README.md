# C++ 408 刷题练习

考研 408（数据结构 / 计算机组成原理 / 操作系统 / 计算机网络）的代码练习与实验记录。

## 目录结构

```
cpp-408-practice/
├── src/          # 练习代码
│   └── main.cpp
├── notes/        # 学习笔记（可放 Markdown）
└── README.md
```

## 环境

| 项目 | 版本 |
|---|---|
| 编译器 | MSVC 14.44（Visual Studio 2022 Community） |
| C++ 标准 | C++17 |
| 平台 | Windows 11 x64 |

## 编译运行

在 VS 2022 中打开 `src/main.cpp`，直接 `Ctrl+F5` 运行；
或命令行使用开发者命令提示符：

```bat
cl /std:c++17 /EHsc src\main.cpp
```
